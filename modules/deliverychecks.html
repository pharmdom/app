What Can You Do Here?
Tap any card to jump straight to that feature.
Show Action Needed
Switch to the Action Needed filter to see only deliveries that still have outstanding tasks — images not yet shared, or SKU label not yet printed.
Show Fully Complete
Switch to the Fully Complete filter to see all deliveries where both images have been shared and the SKU label has been printed.
Show All Arrivals
View every warehouse arrival in one list regardless of task status — useful for a full overview or when searching across all records.
Search Products
Type a product name, supplier name, code, ASIN, or opportunity ID to instantly filter the table in real time. Works within the active filter.
How It Works
Records appear here automatically once a sourcing opportunity is marked as arrived in the warehouse.
1
Delivery arrives — record appears here
When a sourcing opportunity is marked as Warehouse = Yes and Arrived = Yes in the sourcing page, it automatically shows up in this list, sorted by arrival date (most recent first). You don't need to add anything manually.
2
Enter the Bin Location
Click the Bin Location field on any row and type where the stock has been placed in the warehouse (e.g. A1-03). The value is saved automatically when you click away — no save button needed.
3
Toggle Images Shared
Click the Images Shared toggle to mark whether product images have been shared with the relevant team. The toggle switches between Yes (green) and No (red) and saves instantly.
4
Toggle SKU Label Printed
Click the SKU Label Printed toggle once the label has been printed for the product. When both toggles are green, the status dots turn fully green and the row moves off the Action Needed list automatically.
Handy Tips
Little things that make using this page much easier.
The page loads with Action Needed selected by default — so you always open on what still needs doing, not on already-completed records.
When you mark both tasks complete on a row while in Action Needed view, the row fades out smoothly and disappears — keeping the list clean without a manual refresh.
The two status dots on the right of each row give an at-a-glance summary: left dot = Images Shared, right dot = SKU Label Printed. Both green means fully complete.
All changes — bin location and both toggles — save directly without any save button. A brief "Saving…" indicator appears and is replaced by a success or error.
