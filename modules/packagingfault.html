What Can You Do Here?
Tap any card to jump straight to that feature.
Log a Fault
Record a new packaging fault — enter the tracking ID, order number, order date, value, fault type (Warehouse or Digital), and the responsible person.
View Unresolved
Filter to show only faults that haven't been marked as resolved yet — the most important view for active follow-up.

Unlock the 30-day metrics dashboard — total fault value, warehouse vs digital split, and resolution rate. Requires your account password to access.
Search Faults
Search by tracking ID, order number, person, or fault type to find a specific record quickly. Works within whichever filter is currently active.
How It Works
The page tracks every packaging fault from logging through to resolution.
1
Log a fault when an issue occurs
Click Log Fault and fill in the tracking ID, order number, order date, order value, fault type (Warehouse or Digital), and the responsible person. The fault is assigned a unique PF-XXXX ID automatically and saved immediately.
2
Filter and search the fault log
Use the filter pills at the top to narrow by fault type — All, Warehouse, Digital, or Unresolved. Each pill shows a live count. Combine with the search box to find a specific record by tracking ID, order number, or person.
3
Mark faults as resolved
Click the Resolved badge on any row to toggle it between Yes (green) and No (red). Changes save instantly — no save button needed. When viewing Unresolved, resolved rows fade out automatically.
4
Edit or delete existing faults
Click Edit on any row to update any field, change the fault type or person, or delete the record entirely. Deletions require a two-step confirmation to prevent accidents.
5
Unlock the 30-day Metrics dashboard
Click View Metrics to open the metrics bar showing total fault value, warehouse vs digital breakdown with individual values, and overall resolution rate — all scoped to the last 30 days. Access is protected by your account password and stays unlocked for the session.
Handy Tips
Little things that make using this page much easier.
The Unresolved filter is the most useful daily view — it shows only open faults and cleans itself up as you mark things resolved, so you always see exactly what still needs action.
The Metrics bar stays unlocked for your entire browser session once you enter your password — you won't be asked again until you close and reopen the browser.
Clicking Resolved on a row updates the badge colour and saves immediately — no save button, no page reload. If saving fails, the change is automatically reverted and you'll see an error toast.
The Metrics password is your account login password — the same one you use to sign in to the portal. Only authorised users can view the financial breakdown and resolution stats.
