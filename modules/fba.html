What Can You Do Here?
Tap any card to jump straight to that feature.
Add Work
Create a new work item by entering one or more label codes. The system auto-fills prep details from the FBA Products database and groups multiple codes into a single batch record.
View Products
Open the FBA Products database — the master list of all products with their prep instructions, packaging requirements, ASIN, barcode image, and product image.
Work Table
See all work items in a flat table view — searchable, with status badges. Click any row to open its full detail drawer for editing.
View Completed
See all records that have completed the full pipeline — units completed, UPS collected, and Veeqo stock adjusted.
How It Works
Every FBA shipment follows a four-stage flow across two Kanban columns.
1
Add a product to the FBA database
Click Products → Add Product to create an FBA product record. Set the label code, brand, ASIN, all prep options (poly bag, warning label, barcode, box, bundle, DG label), and upload the product image and barcode image. This becomes the prep reference for all future work items.
2
Create a work item
Click Work → Add Work and enter one or more label codes with their unit quantities. The system auto-matches each code to the FBA Products database and shows the full prep brief. Multiple label codes become a single batch work item. Add a grouping link, collection date, and grouping images if needed.
3
Work through the Kanban board
New work items land in Warehouse. Click any card to open the detail drawer. The Warehouse tab lets you mark units completed and toggle UPS Collected. Once units are completed and UPS is collected, the card moves to Digital Ops — where Veeqo Stock Adjusted is toggled. After that, the record is Completed.
4
Track completion
The green Completed chip in the header shows how many records have finished the full pipeline. Click it to see the full completed list. All data syncs to Supabase in real time — changes made on any device are reflected immediately.
Handy Tips
Little things that make using this page much easier.
A work item's Kanban column is determined automatically by its data — not by dragging. Units Completed + UPS Collected → Digital Ops. Then Veeqo Stock Adjusted → Completed. You can never move a card to the wrong stage.
When adding work with multiple label codes, all codes are grouped into a single batch work item. The drawer shows each product's image, prep options, and barcode in a numbered list — so the warehouse team sees everything they need in one place.
The Delete button requires two clicks — the first click turns it red and says "Confirm?", and you have 3 seconds to click again to confirm. This prevents accidental deletions. The button resets automatically if you don't confirm.
You can upload PDF files for both product images and barcode images — they are automatically converted to PNG on upload. Existing Google Drive image URLs are displayed as-is; only new uploads go to Supabase Storage.
